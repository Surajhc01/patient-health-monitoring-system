# 🏥 Patient Health Monitoring Alert System

A real-time health monitoring platform that tracks patient vitals using sensors and sends alerts when readings cross normal range.

## 📌 About the Project
This system monitors patient health parameters in real-time, stores data securely on the cloud, and triggers alerts when any vital sign goes beyond the safe range.

## ✨ Features
- 🌡️ Monitors body temperature, heart rate and pulse rate
- ☁️ Stores all readings securely on the cloud
- 🚨 Sends alerts when health parameters cross normal range
- 📊 Real-time data monitoring and tracking
- ✅ Tested for accuracy, reliability and performance

## 🛠️ Tech Stack
- **Language:** Python
- **Hardware:** IoT Sensors
- **Cloud:** Cloud Storage Integration
- **Database:** SQL
